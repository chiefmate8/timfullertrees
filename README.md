# T Fuller Arborist website

The website for my dad's family tree surgery business in Hertfordshire and Essex. It's a single page with the services, a short bit about the business and a form to request a free quote.

Live site: https://www.timfullertrees.com

## What it does

- Shows what the business does, with a section for each service
- Has a quote request form that sends the message by email through Formspree
- Includes schema.org structured data so search engines can show the business details

## Tech

| Area | What |
| --- | --- |
| Page | One HTML file with the CSS inside it, no JavaScript and no build step |
| Fonts | Playfair Display, Lato and Cormorant Garamond from Google Fonts |
| Contact form | Formspree |
| Hosting | GitHub Pages with a custom domain |

## Repo layout

```
index.html           the whole page
hero-bg.JPG          the background photo
favicon-32x32.png    the tab icon
CNAME                the custom domain for GitHub Pages
```

## Updating

Change `index.html` and commit to `main`. GitHub Pages then publishes the update to the live site.
